# Revisión visual de variantes — Apollo ámbar

Fecha: 2026-10-20

Se revisó la galería original del producto `frasco-apollo-vidrio-125-ml-ambar-con-tapa-difusora` y se compararon visualmente las seis imágenes de accesorio (archivos de revisión locales `research/apollo-ambar-1.jpg` a `research/apollo-ambar-6.jpg`) con los nombres oficiales de variante. Cada imagen muestra el mismo frasco ámbar con el accesorio nombrado: aluminio oro, aluminio plata, brillo negra, brillo plata, brillo oro y madera cónica. Se vincularon las seis variantes a sus respectivas imágenes originales de galería; no se generó ni se alteró ninguna imagen.

Las asociaciones se guardan en `src/data/variant-photography.json`, que prevalece sobre las referencias compartidas. No se cambiaron productos, accesorios ni precios.
